# 📚 Supervised Machine Learning

Learning from being given "right answer".

We give training data to learning algorithm to learn from them. The training data will have input(X) and output label(Y).

## 🔧 Algorithms Implemented

### 📈 Regression

* Linear Regression - prediction from a number infinitely many possible numbers
* Example: House price detection

### 🔍 Classification

* Logistic Regression - Predict categories from small number of possible outputs
* Example: Breast cancer detection
